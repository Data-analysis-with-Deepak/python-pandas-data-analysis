Welcome to my Python Pandas Data Analytics repository!

## Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Data-analysis-with-Deepak/python-pandas-data-analysis.git
```

Navigate into the project:

```bash
cd python-pandas-data-analysis
```

Install dependencies:

```bash
pip install pandas numpy jupyterlab openpyxl
```

Start JupyterLab:

```bash
jupyter lab
```
